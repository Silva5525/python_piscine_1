# python_piscine_1

Training Piscine Python for datascience - 1

## 📌 About

This repository contains practice code focused on core Python concepts, including arrays, list operations, image loading, image manipulation, and basic NumPy usage.

## ⚙️ Requirements

* Python **3.10+**
* Linux environment recommended
* `flake8`
* `numpy`
* optionally `Pillow` and `matplotlib` for the image exercises

Check your Python version:

```bash
python3 --version
```

## 🧪 Test and Style Check

Run the tester of an exercise:

```bash
python3 ex00/tester.py
```

Check the code style with flake8:

```bash
flake8 .
```

## 🐍 Create and Activate a Virtual Environment

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

## 📦 Install Dependencies

Install NumPy:

```bash
pip install numpy
```

For the image exercises, you may also need:

```bash
pip install pillow matplotlib
```

## ▶️ Run an Exercise

From the project root:

```bash
python3 ex00/tester.py
```
